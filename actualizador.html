Actualizador de Datos del Portal

Genera el index.html actualizado del Portal de Pronóstico de Cartera Q2 — sin programar.

Cómo funciona

  1. Esta herramienta tiene embebida la plantilla del portal — no requiere conexión al repositorio.
  2. Arrastra tu Cierre Q2 2026.xlsx (y opcionalmente el ZREPO).
  3. Descarga el index.html generado y súbelo a GitHub.

1 · Portal base

✅ Plantilla del portal embebida en esta herramienta

2 · Carga el Excel

Arrastra aquí tu Cierre Q2 2026.xlsx
o haz clic para seleccionarlo · puedes añadir también el ZREPO.xlsx
⬜ Cierre Q2 2026.xlsx — requerido
⬜ ZREPO.xlsx — opcional
Sin ZREPO nuevo: se conservarán los datos de cobranza por mes que ya tiene el portal.

3 · Genera el archivo

Revisa que los totales de arriba se vean correctos antes de subir el archivo.

4 · Súbelo a GitHub

Una vez descargado el index.html:
  1. Entra a tu repositorio portal-pronostico-q2 en GitHub.
  2. Botón Add file → Upload files.
  3. Arrastra el index.html recién descargado (reemplaza al anterior).
  4. Deja marcado Commit directly to the main branch y haz clic en Commit changes.
  5. Espera 1–2 minutos y refresca el portal con Ctrl+F5.
